## Заметки для фазы 2 (по итогам прогона)

- Бутстрап connections без события: брать `business_connection_id` из
  входящих сообщений и опрашивать `getBusinessConnection`.
- Черновики-варианты: при одобрении одного варианта помечать остальные
  черновики того же чата `superseded`; TTL ~24 ч (окно ответа всё равно
  умирает); MCP-инструмент `list_drafts`, чтобы агент видел висящие и
  отклонённые варианты между сессиями.
- Кнопку «❌ Отклонить» оставляем: явный сигнал «владелец забраковал» —
  ценные данные для агента, молчание неоднозначно.
